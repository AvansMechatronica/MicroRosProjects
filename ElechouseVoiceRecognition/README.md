# Voice Recognition V3 for ROS-Jazzy

## Note
This package is a ROS2 implementation of the voice recognition system for the ROS-Jazzy project. It utilizes the `speech_recognition` library to capture and process audio input from a microphone, converting it into text commands that can be used within the ROS ecosystem.


## More details can be found in the [Elechouse Voice Recognition GitHub Repository](https://github.com/AvansMechatronica/ElechouseVoiceRecognition)
